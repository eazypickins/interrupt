# INTERRUPT — Posts 01–20 (Omni / Veo Production Scripts)

Combined from `01_FIRST_10_POST_SCRIPTS.md` and `04_POSTS_11-20.md`, reformatted
clip-by-clip for AI video generation (Google Omni / Veo).

---

## PRODUCTION RULES

1. **Each clip is a separate generation.** Omni max 10s/clip · Veo max 8s/clip.
   This plan uses **4–6s clips**.
2. **Finished videos are 25–35 seconds.**
3. **The first 1–2 seconds must contain the pattern interrupt** (the grab).
4. **Text is NEVER generated by the AI.** Add all `Overlay` text in CapCut.
5. **Proof clips use REAL screenshots** — never AI-generate a fake result.
6. **AI video = the motion; stills = the text/graphics.**
7. Every clip lists: **Visual** (the AI prompt), **Overlay** (on-screen text),
   **Narration** (voiceover).
8. Add the **intro (0.6s)** before Clip 1 and the **outro (1.2s)** after the last clip.
9. Same voice, same caption style, same sound design on every post.

## STANDARD CLIP STRUCTURE

| Clip | Timing | Job |
|---|---|---|
| Clip 1 — GRAB | 0:00–0:04 | The pattern-interrupt visual |
| Clip 2 — LABEL | 0:04–0:10 | Category + first teaching line |
| Clip 3 — TEACH | 0:10–0:16 | The mechanism |
| Clip 4 — PROOF | 0:16–0:22 | The receipt (real screenshot / result) |
| Clip 5 — CTA | 0:22–0:28 | One call to action |

Not every post uses all five — adapt as noted.
