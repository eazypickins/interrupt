## How to post each one

1. **Upload** the assembled video (intro + visual + outro).
2. **Paste the caption** for that platform.
3. **Paste the hashtags** into the caption (or the first comment — either works).
4. **Publish**, then **immediately post the pinned comment** from your own account.
5. **Reply to every comment** for the first 90 days — as a human, first person.
6. **Log the post** in `03_PROOF_CAPTURE_TRACKER.md` (views 24h, 3s hold, etc.).

## Hashtag strategy (why these)
- **Reach tags** (big volume): `#aivideo` `#aivideos` `#sora2` `#veo3` `#aitiktok` `#viralvideo`
- **Creator tags** (your buyer): `#contentcreator` `#contentstrategy` `#hook` `#socialmediatips` `#growth`
- **Niche tags** (low competition, on-brand): `#scrollstopper` `#patterninterrupt` `#hookideas`

Use **8–12** per post. Keep the same core set so the algorithm learns your topic.
**Rotate** the reach tags slightly per post to test which pull best.

## Posting notes
- **TikTok:** post when your audience is active; reply to the first comments fast.
- **Instagram:** also post the same clip as a Reel; put the link in bio (not caption).
- **YouTube Shorts:** use the searchable caption + `#Shorts` in the title/description.
- **Never** post two conversion/salesy posts back to back — Post 1–3 are safe.
- **3-second hold is the metric to watch** — target 70–80%.
