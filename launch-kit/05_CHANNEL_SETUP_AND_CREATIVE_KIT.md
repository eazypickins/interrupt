## PART 4 — AI image-generation prompts

### ⚠️ The one rule that matters
**AI image models are bad at text.** Generate the *visual* with AI, then add the
wordmark "INTERRUPT" in **Canva or Figma** using **Space Grotesk** (bold).
For logo text rendered directly, use **Ideogram 3.0** or **Recraft** (best-in-class
text rendering).

**Brand lock (put this in every prompt):**
- Charcoal background `#1C1C1E`
- Orange accent/rim light `#FF6A00`
- Violet glow `#3B1F8F`
- Minimal, high contrast, lots of negative space
- The recurring motif: **a floating object (gravity break)**

---

### 4.1 — Logo / icon mark

**Prompt A — icon mark (floating object + broken line):**
```
A minimal vector icon: a single glossy red apple floating in mid-air, a thin
horizontal orange line broken in the middle beneath it, solid deep charcoal
background (#1C1C1E), soft orange rim light (#FF6A00), flat vector style,
centered, generous negative space, high contrast, square.
```
**Negative:** `text, letters, words, gradient noise, busy background, drop shadow clutter`

**Prompt B — wordmark (use Ideogram 3.0):**
```
The word "INTERRUPT" in bold geometric sans-serif, all caps, white, with an
orange period at the end, on a solid charcoal background, centered, minimal,
flat vector, high contrast, generous margin.
```
**Then:** export as PNG (transparent where possible) + SVG. Use this everywhere.

A single glossy red apple floating in mid-air against a deep charcoal background

**Crop note:** Keep the apple centered with margin so it survives circular crops.

## PART 5 — Tool recommendations

| Job | Best tool | Why |
|---|---|---|
| Logo text / wordmark | **Ideogram 3.0** or **Recraft** | Only models that render text cleanly |
| Photoreal hero visuals | **Midjourney v7** | Best composition + lighting |
| Consistent style across images | **Flux** (style reference) | Keeps the palette/motif locked |
| Avatar variations | **GPT Image / DALL·E** | Easy iteration on the apple motif |
| Final assembly, exact sizes, text | **Canva** or **Figma** | Pixel-exact dimensions + Space Grotesk |

**Workflow:** generate visuals in AI → import to Canva → add wordmark + text at
exact dimensions → export per platform.
