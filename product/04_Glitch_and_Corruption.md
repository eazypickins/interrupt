# Deep-Dive 04 — Glitch & Digital Corruption
## The Complete Sub-Technique Library (17 Prompt Variations)

> Part of the Scroll Interrupter Master System. Glitch interrupts signal
> "something is broken" — the brain checks if the screen, the app, or reality
> itself is failing. That check is a scroll-stop.

---

## Why This Category Wins

Glitch aesthetics exploit the brain's automatic "error detection." When the image
tears, corrupts, or dissolves into pixels, the viewer's first instinct is "is my
phone broken?" — and they stay to confirm. Glitch is also culturally coded as
*edgy, techy, and modern*, so it aligns with brands targeting younger,
digitally-native audiences.

**Use this category when you need:** an edgy/tech vibe, a "the matrix broke"
moment, or to visually represent disruption, revelation, or a lie being exposed.

## Sub-Technique Library

### 4.1 — GLITCH / SCANLINE CORRUPTION

**Prompt 1 — Classic RGB Glitch:**
```
Digital glitch effect: [a subject/action] becomes corrupted by [RGB color-split,
scanlines, pixel displacement], the image tearing and distorting as if the
video signal is breaking, then momentarily recovering. Cyberpunk glitch
aesthetic, locked camera, 9:16 vertical.
```
**Negative:** clean image, no distortion, smooth motion, static glitch throughout.

**Prompt 2 — Portrait Glitch Reveal:**
```
Glitch reveal: [a clean portrait of a person] suddenly glitches — horizontal
tears, color channels separating, the face fragmenting — then snaps back
sharper and more vivid. Edgy, modern, locked camera, 9:16 vertical.
```
**Negative:** no glitch, clean portrait, no reveal, soft fade, static.

**Prompt 3 — Glitching World:**
```
A [person] walks through [a normal scene] that periodically glitches —
buildings, sky, and objects flickering and pixelating around them while they
stay crisp. The glitch reveals [something hidden] beneath reality. Cinematic,
locked camera, 9:16 vertical.
```
**Negative:** world static, no glitch, subject glitching too, no reveal.

### 4.2 — PIXEL DISSOLVE (Matter Becomes Pixels)

**Prompt 4 — Person Dissolves Into Pixels:**
```
Pixel-dissolve effect: a [person] disintegrates into [glowing pixels / digital
particles] that drift apart and swirl, then reassembles back into solid form.
Smooth transition, futuristic clean aesthetic, locked camera, 9:16 vertical.
```
**Negative:** hard cut, no transition, disappearing without particles, smoke instead of pixels.

**Prompt 5 — Object Pixelates Away:**
```
Pixel-dissolve: a [solid object] breaks apart into [thousands of tiny colored
pixels] that scatter and fade, then converge back and reform the object. Clean,
satisfying, digital aesthetic, locked camera, 9:16 vertical.
```
**Negative:** hard cut, no pixelation, smoke, permanent disappearance, no reform.

**Prompt 6 — Transition Through Pixels:**
```
Pixel transition: [scene A] dissolves into [a field of glowing pixels] that
swirl and re-form into [scene B], creating a seamless futuristic wipe. Smooth,
clean, locked camera, 9:16 vertical.
```
**Negative:** hard cut, no transition, no pixels, broken continuity, muddled.

### 4.3 — VHS / SCREEN TEAR

**Prompt 7 — VHS Aesthetic:**
```
VHS tape aesthetic: [a subject/action] shot as degraded analog video —
horizontal tracking errors, color bleed, scanlines, grain, occasional signal
loss. Warm retro color cast, locked camera, 9:16 vertical.
```
**Negative:** clean digital, modern clarity, no grain, stable image.

**Prompt 8 — VHS Rewind / Fast-Forward:**
```
VHS effect: [a scene] plays with visible VHS fast-forward / rewind artifacts —
horizontal streaks, distorted audio bar, garbled tracking — then snaps into
clean playback. Retro, nostalgic, locked camera, 9:16 vertical.
```
**Negative:** clean playback, no artifacts, no retro feel, modern clarity.

**Prompt 9 — Camcorder / Home Video:**
```
Camcorder aesthetic: [a subject] shot on a handheld 90s camcorder — date stamp
in the corner, soft focus, color fringe, slight instability, warm retro tones.
Authentic home-video feel, 9:16 vertical.
```
**Negative:** modern clarity, no date stamp, stable image, clean digital.

### 4.4 — LIQUIFY / MELT

**Prompt 10 — Person Melts:**
```
Liquify effect: a [person] begins to melt and drip downward like [wax/honey],
warping and distorting while retaining recognizable features, then slowly
re-forms. Surreal, glossy liquid lighting, locked camera, 9:16 vertical.
```
**Negative:** solid form, rigid, no distortion, frozen, dry texture.

**Prompt 11 — Object Drips:**
```
Liquify effect: [a solid object] melts into [a puddle of liquid] that drips and
spreads, its form warping, then reforms back into the solid object. Glossy,
surreal, clean lighting, locked camera, 9:16 vertical.
```
**Negative:** solid, no drip, no warp, dry, permanent melt, no reform.

**Prompt 12 — Screen Melt (Matrix Style):**
```
Screen-melt effect: the frame itself melts and drips downward like [molten
glass / digital liquid], warping [the subject] as the world runs like paint,
then solidifies. Psychedelic, vivid, locked camera, 9:16 vertical.
```
**Negative:** solid frame, no melt, no warp, static, no recovery.

### 4.5 — DATA-MOSH / COMPRESSION ARTIFACT

**Prompt 13 — Motion Data-Mosh:**
```
Data-mosh effect: when [the subject moves], blocks of the image smear, lag, and
distort, creating a corrupted-compression aesthetic, as if the video file is
failing. Saturated colors, digital artifacts, locked camera, 9:16 vertical.
```
**Negative:** clean motion, no artifacts, stable pixels, smooth footage.

**Prompt 14 — Compression Collapse:**
```
Data-mosh: [a scene] breaks down into [macro-block compression artifacts],
large pixelated squares smearing across the frame, the image degrading and
recovering in waves. Saturated, glitchy, locked camera, 9:16 vertical.
```
**Negative:** clean image, no artifacts, stable, no degradation.

**Prompt 15 — Color Bleed / Chromatic Aberration:**
```
Chromatic aberration: [the subject] has visible color-fringing — red and cyan
edges separating at high-contrast boundaries — as if shot through a flawed
lens, plus subtle digital warping. Modern, edgy, locked camera, 9:16 vertical.
```
**Negative:** clean edges, no fringing, no aberration, soft focus.

### 4.6 — HOLOGRAM / PROJECTION GLITCH

**Prompt 16 — Hologram Flicker:**
```
Hologram effect: [a person/object] appears as a flickering hologram —
translucent, with scanlines and intermittent signal dropouts, hovering in a
dark room. Sci-fi, blue-tinted light, locked camera, 9:16 vertical.
```
**Negative:** solid opaque, no flicker, no scanlines, no glow, full color.

**Prompt 17 — Projection Malfunction:**
```
Hologram malfunction: [a holographic figure] glitches and tears, its projection
breaking apart into static and pixel fragments, struggling to hold form, then
stabilizing. Futuristic, dark, neon-accented, locked camera, 9:16 vertical.
```
**Negative:** stable hologram, no glitch, solid figure, no breakdown, bright room.

## Negative-Prompt Cheat Sheet (Glitch Category)

```
clean image, no distortion, smooth motion, stable pixels, modern clarity,
static glitch throughout, no recovery, hard cuts, text, watermark, logo,
play button, blurry
```

## Teaching Tip (For Your Product)

Glitch interrupts teach one core lesson: **"broken" is an attention signal.**
The brain is hardwired to investigate errors. The skill is using glitch
*sparingly and with purpose* — the glitch should always mean something (a lie
exposed, a reveal, a disruption), never just decoration. Teach students to ask:
"what is breaking, and why?"
