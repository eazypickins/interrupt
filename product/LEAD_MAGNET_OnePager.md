# The 12 Scroll Interrupters
## Stop the Scroll in 0.8 Seconds — The One-Pager

**Every viral hook does one of three things to the brain:**
breaks reality · shouts louder than the feed · opens a loop it must close

**The 12 categories below cover all three.** Learn these, and you'll never
stare at a blank prompt again.

## THE 3-PART FORMULA (the only rule you need)

Every scroll interrupter works because it follows:

**Pattern Interrupt (0–0.8s) → Identity Signal (0.8–1.5s) → Open Loop (1.5–3s)**

1. **Interrupt** — break reality or shout, instantly.
2. **Identity** — make the viewer feel "this is about me."
3. **Open loop** — leave an unanswered question so they stay.

---

## THE AI PROMPT FORMULA (6 parts)

```
1. CAMERA & FRAME — locked camera, 9:16 vertical, no unwanted motion
2. SUBJECT & ACTION — who/what, doing what
3. EFFECT / MECHANISM — the named interrupt, as physical behavior
4. ENVIRONMENT — background, light, mood
5. STYLE / MEDIUM — photoreal / 3D / paper / clay / VHS
6. NEGATIVE PROMPT — the failure modes to exclude
```

**The golden rule:** state the interrupt as a *verb + direction*, not a vibe.
Write "the water flows upward into the glass" — never "surreal water."

## THE 20-SECOND NEGATIVE PROMPT (save this)

```
frozen limbs, rigid pose, standing, walking normally, floating upright,
normal physics, ground contact, strings, wires, visible hands, extra limbs,
distorted anatomy, wrong number of fingers, blurry subject, jump cuts,
broken motion, hard cuts, camera shake, text, watermark, logo, play button
```

## WHICH ONE DO I USE TODAY?

Ask yourself three questions:

1. **What should the viewer FEEL?** (awe → gravity/scale · unease → mirror/body · energy → camera/glitch)
2. **Does it need to work on mute?** (if yes → typography/text)
3. **Am I selling, teaching, or storytelling?** (selling → light/color · teaching → time/scale · storytelling → emotion/impossible)

The interrupt serves the emotion. Not the other way around.
