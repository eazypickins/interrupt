# Deep-Dive 12 — Typography & Text
## The Complete Sub-Technique Library (15 Prompt Variations)

> Part of the Scroll Interrupter Master System. Text interrupts are the
> mute-proof hook — the one interrupt that works even with sound off and no
> visual spectacle. Bold, kinetic, or shattering text is un-missable.

---

## Why This Category Wins

85% of short-form video is watched on mute. Text interrupts are the only
category that *communicates a message* in the first 0.8 seconds without sound.
Big, fast, high-contrast text is also the single most reliable way to make a
hook readable while the visual does the emotional work.

**Use this category when you need:** a mute-proof hook, a message-first post,
or to visualize a word/concept literally (shatter, morph, count).

---

## Sub-Technique Library

### 12.1 — KINETIC TEXT SLAM

**Prompt 1 — Text Slam:**
```
Kinetic text: bold text [slams / types / pops] onto the screen in large,
high-contrast lettering, timed to [a beat / an action], conveying [a short
message]. The text dominates the frame. 9:16 vertical.
```
**Negative:** small text, slow text, low contrast, unreadable, no motion.

**Prompt 2 — Word-by-Word Reveal:**
```
Kinetic text: words appear one by one in rapid succession, each slamming into
place, building [a sentence / a hook] with impact, timed to [a beat]. Bold,
high-contrast, large, 9:16 vertical.
```
**Negative:** static sentence, slow, low contrast, unreadable, no build.

**Prompt 3 — Beat-Synced Typography:**
```
Kinetic text: [a short phrase] pops and pulses in sync with [a music beat /
a rhythmic action], each word or syllable hitting on the beat, bold and
high-contrast. Energetic, 9:16 vertical.
```
**Negative:** no sync, static, low contrast, slow, no rhythm.

---

### 12.2 — SHATTER / GLITCH TEXT

**Prompt 4 — Text Shatters Like Glass:**
```
Shattering text: [a word or phrase] appears on screen, then [shatters like
glass] into fragments, visually mirroring [the message it conveys]. The
shatter is sharp and dramatic. 9:16 vertical.
```
**Negative:** static text, no break, soft fade, unbroken word.

**Prompt 5 — Text Glitches Apart:**
```
Glitching text: [a word] appears, then glitches — pixelating, tearing, RGB
splitting — before breaking apart or resolving into [a new word]. Digital,
edgy, clean, 9:16 vertical.
```
**Negative:** static text, no glitch, no transformation, soft fade, unreadable.

**Prompt 6 — The Lie Shatters (Message-Reveal):**
```
Shattering text: the word [A] appears bold on screen, then shatters and is
replaced by [B] — the visual break mirroring [a lie being exposed / a truth
revealed]. Sharp, dramatic, readable, 9:16 vertical.
```
**Negative:** no shatter, no replacement, static, muddled, no contrast.

---

### 12.3 — TEXT-IN-WORLD (Text Interacts With the Environment)

**Prompt 7 — Person Leans on a Word:**
```
Text-in-world: [a word or phrase] exists as a physical object in the scene —
the subject [leans on / walks through / interacts with] the 3D text, which
casts realistic shadows and occludes correctly. Dimensional, cinematic,
9:16 vertical.
```
**Negative:** flat overlay, no interaction, text not integrated, no shadows.

**Prompt 8 — Walking Through Letters:**
```
Text-in-world: a [person] walks through [giant 3D letters] standing in a real
environment, the letters casting shadows and the person passing between them.
Dimensional, cinematic, locked camera, 9:16 vertical.
```
**Negative:** flat text, no depth, no interaction, no shadows, overlay.

**Prompt 9 — Text on the Ground:**
```
Text-in-world: [a word] is painted on [the ground / a wall], and a [person]
walks over or past it, the text integrated into the environment with real
perspective and texture. Cinematic, locked camera, 9:16 vertical.
```
**Negative:** flat overlay, no perspective, no texture, floating text, no integration.

---

### 12.4 — COUNTING / NUMBERS REVEAL

**Prompt 10 — Counting Up:**
```
Counting reveal: a [number / statistic] counts up rapidly on screen with
[dramatic styling], revealing [a final figure], while [a subject/action] plays
behind. The number is large and readable. 9:16 vertical.
```
**Negative:** static number, no count, unreadable, small text, no build-up.

**Prompt 11 — Countdown to Reveal:**
```
Countdown: a number counts down from [10 / 5 / 3] to [1 / 0], building
anticipation, before [a reveal / a moment] lands. Large, dramatic, readable,
9:16 vertical.
```
**Negative:** no countdown, static, no reveal, unreadable, no build.

**Prompt 12 — Money Counter:**
```
Money counter: [a dollar / naira amount] counts up rapidly on screen,
the number climbing to [a final figure], over [a product / a result],
dramatic and aspirational. Large, readable, 9:16 vertical.
```
**Negative:** static amount, no count, unreadable, small, no drama.

---

### 12.5 — TEXT MORPH (Word Transforms)

**Prompt 13 — "Broken" → "Growing":**
```
Text morph: the word [A] transforms smoothly into the word [B], letter by
letter, on screen — [e.g., "broken" morphs into "growing"]. The transition is
fluid and legible throughout. 9:16 vertical.
```
**Negative:** hard cut between words, illegible morph, no transformation, static.

**Prompt 14 — Handwriting Appears:**
```
Handwriting effect: [a message] writes itself on screen as if by an invisible
hand, in a [warm handwritten style], letter by letter, the words appearing
naturally. Intimate, warm, 9:16 vertical.
```
**Negative:** static text, typed look, no handwriting, instant full text, cold.

**Prompt 15 — Word Fills With Color:**
```
Text fill: [a word] starts as an outline and fills with [color / texture /
pattern] from one side to the other, the fill mirroring [a concept — progress,
emotion, energy]. Clean, satisfying, 9:16 vertical.
```
**Negative:** static fill, no progression, instant, muddled, no concept.

```
small text, slow text, low contrast, unreadable, static text, no motion,

```

## Teaching Tip (For Your Product)

Typography interrupts teach one core lesson: **text is a visual, not just a
message.** The way text *moves* — slams, shatters, writes itself — does as much
emotional work as the words themselves. The skill is matching the *motion* to
the *meaning*: a lie shatters, a truth writes itself, a number counts up. Teach
students: the motion IS the message.
